# Scientific Calculator

A Python-based scientific calculator that performs both basic and advanced mathematical operations through a command-line interface.

## Features

- Basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Exponentiation
- Square Root
- Logarithmic Functions
- Trigonometric Functions
- Factorial
- Percentage
- Input validation and error handling

## Technologies Used

- Python 3
- math module

## Installation

```bash
git clone https://github.com/PRANJALxDEVxAI/scientific-calculator-python.git
cd scientific-calculator-python
```

## Usage

```bash
python main.py
```

> Replace `main.py` with your actual Python file name if it is different.
